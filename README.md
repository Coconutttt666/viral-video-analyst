# 自媒体高手 · 爆款视频分析师（viral-video-analyst）

一个用于 Claude / ZCode 的 **Skill**：把爆款视频逆向工程成可复用的公式，再把公式落到具体选题、分镜表和台词上。

核心价值是**模式识别**——从一个案例里找出可迁移的结构，而不是产出一份只适用于该案例的评论。

## 它能做什么

| 场景 | 输出 |
| --- | --- |
| 拆解一个爆款视频 / 一个主题为什么火 | 四步分析：结构与节奏、观众心理、算法亲和度、爆款 DNA |
| 要可复制的策略 | 策略蓝图（保留什么 / 优化什么）、风险与规避、3–5 条写作 SOP |
| 要新选题 | 5 个新选题，含标题、核心钩子、成功率预判 |
| 要分镜脚本 | 完整分镜表（时间码 / 景别 / 声音 / 字卡 / 剪辑提示） |
| 要配音台词 | 全片配音文稿，含语态、气口、字数控制纪律 |
| 素材拍回来和原方案不符 | 核对缺口 → 换钩子 / 换骨架 → 跨天串联 → 事实自查 |
| 要做攻略片 / 避坑片 | 主题公式、信息反转结构、干货段写法、价格合规边界 |
| 不会做字卡 | 字体 / 字号 / 颜色 / 动效规格 + 两个范例 + 验收标准 |

## 目录结构

```
viral-video-analyst/
├── SKILL.md                          # 主文件：路由、四步工作流、核心准则
└── references/
    ├── analysis-framework.md         # 四步流程详解 + 通用钩子与模式库
    ├── production-templates.md       # 分镜 / 拍摄 / 声音 / 字卡 / 配乐模板
    ├── footage-adaptation.md         # 素材与原方案不符时的处理流程
    ├── title-card-spec.md            # 字卡样式、动效、验收标准
    ├── guide-video-playbook.md       # 攻略片 / 干货片 / 避坑片手册
    └── case-library.md               # 真实案例拆解范例
```

采用**渐进式披露**设计：SKILL.md 只在触发时加载，references 按需读取，不占用不必要的上下文。

## 安装

把 `viral-video-analyst/` 目录放进你的 skills 目录即可：

| 环境 | 路径 |
| --- | --- |
| 用户级（全局可用） | `~/.agents/skills/` |
| 项目级（仅当前项目） | `<项目>/.agents/skills/` |

```bash
# 示例：克隆到用户级 skills 目录
git clone https://github.com/Coconutttt666/viral-video-analyst.git \
  ~/.agents/skills/viral-video-analyst
```

安装后在对话里说「帮我拆解这个视频」「这条片子该怎么剪」「字卡怎么做」，即可自动触发。
也可以直接喊中文名 **「自媒体高手」**。

## 四步工作流

1. **深度拆解与数据标注**——结构与节奏、观众心理、算法亲和度
2. **提取爆款 DNA**（会停下等你确认）
3. **策略蓝图**——可复制策略、风险规避、写作 SOP（确认第二步后才执行）
4. **5 个可扩展新选题**（确认第三步后才执行）

## 四条核心纪律

- **区分事实与推断**——素材描述未经本人确认，不得当作既定事实继续推演
- **素材决定结构**——实际素材与原方案不符时，先核对缺口，再重排结构
- **关键前提必须先求证**——一个没问清的数字（比如单价是单人还是两人），可以让整个结构作废
- **无画面不等于无内容**——先判断这段是"展示"还是"解释"，是解释就交给字卡

## 不适用

- 视频剪辑执行（本 skill 只出方案，不剪片）
- 纯数据分析任务
