# 素材适配与串联

## 核心原则

**素材决定结构，不是结构决定素材。**

原方案是理想化的。用户实际能拍到的往往受制于现实约束（教练严格、天气、时间、同行者配合度）。当承重镜头缺失时：

- **不要**假设素材存在而继续按原方案写；
- **不要**让用户为原方案去补拍不可能补拍的东西；
- **要**先核对缺口，再判断是"换钩子"还是"换骨架"。

**缺口可以变成主题。** "没拍到"本身常常是比"拍到了"更强的信息差钩子。例：水下镜头被教练禁止拍摄 → 钩子变成"教练不让我们带相机下水，所以水下的每一秒都是借来的"。把一个劣势转成全片独占的结构。

## 第一步：核对缺口

对照原方案，逐项标注：

| 状态 | 含义 | 处理 |
| --- | --- | --- |
| ✅ 有 | 素材已拍到 | 直接用 |
| ⭐ 超出预期 | 拍到了原方案没预料的东西 | 可能是新的结构支点，重点评估 |
| ⚠️ 缺失 | 原方案的承重镜头没拍到 | 进入第二步判断 |
| ⚠️ 不足 | 拍到了但量/时长不够 | 判断能否用剪辑手法弥补（快切、集中使用） |

**向用户确认素材时必须问清三件事**：每组的**条数**、**总时长**、**是否同时拍到人脸**。这三项直接决定结构。

不要凭用户的口头描述就下结论。用户说"有海边素材"，实际可能只有 3 张照片。

**最常见的误判**：用户说"教练比较严格，不让拍"，就当成"全程没有素材"。**实际可能是分阶段的**——某些潜次不允许拍、某些潜次允许甚至教练帮拍。凡是出现"受限""严格""不让"这类词，必须追问：**是所有时候都不行，还是只有某几个阶段不行？拍到的具体有多少？**

**这条纪律的代价**（见 case-library.md 案例一）：因未追问这一点，连续三个版本都建立在"几乎没有水下素材"的错误前提上，还额外做了一整套 AI 替代方案——全部作废。**一个没问清的素材情况，可以让数十页方案归零。**

## 第二步：判断是否换骨架

看缺失的是不是**承重墙**：

- **承重墙 = 主钩子素材、情绪峰值、静音段长镜头、身份跃迁凭证。** 缺任何一面，骨架必须改。
- **非承重 = 空镜、过渡镜头、次要 B-roll。** 缺了用现有素材替代或加字卡过渡。

改骨架的两个方向：

1. **换钩子不换结构**：结构还在，只是开场那一镜换一个（例如恐惧前置 → 信息差前置）。
2. **换结构**：主线整个重排，用"多出来的素材"（⭐ 超出预期项）当新的承重墙。

**判断依据**：如果缺失的镜头恰好是原方案情绪最高点（如潜水的静音段），就要找一个新的情绪高点来替代，而不是硬撑。

## 第三步：跨场景 / 跨天串联

用户素材经常**不在同一天拍**（潜水一天、逛街另一天）。这时不要按时间顺序排——按时间排会让观众读出"流水账断层"。

### 关键认知

**观众看的是动线，不是日程表。** 只要片中不出现日期、配音不说"第二天我们去了 X"，观众默认这是一次连续体验。

会暴露断层的只有四件事：
1. 光线跳变（正午硬光 → 傍晚暖光硬接）
2. 服装跳变
3. 字幕写日期
4. 配音说日期

### 三根缝合绳

**绳 1｜主题物件的递减（主绳）**
找一个贯穿性的东西，让它在片中按"递减/递进"出现。例：水 → 潜水（在水下）→ 另一项水上活动（在水上）→ 海边（只看着水）。这条递减曲线本身就是情绪线，观众跟着它走，不需要知道隔了几天。

**绳 2｜光的一天（暗绳）**
用光当时间过渡器：白天 → 暖光（室内/傍晚）→ 落日。观众读到的是一天。**不需要任何字幕，光自己会说话。**

**绳 3｜承诺物件的往返（钩子绳）**
找一个物件在**开头闪一帧预告**（0.5 秒，不解释），全片不提，结尾兑现。这一帧是给观众的承诺——有了它，中间怎么跳观众都愿意跟。例：开头闪一帧签字特写 → 结尾才揭示那是证书。

### 四种缝合手法

| 手法 | 怎么用 | 效果 |
| --- | --- | --- |
| **A. 动作匹配** | 上一镜和下一镜有相同动作/形状，直接接。水中挥手 → 街上招手 | 同一动作跨场景复现，观众脑补"他们一直这样" |
| **B. 声音先行** | 下一镜的声音提前 0.5–1 秒进入（画面还没切） | 听感先过来，画面切过去不突兀 |
| **C. 空镜当胶水** | 每次场景切换垫 1–2 秒空镜（云/海/天空/街角） | 空镜是剪辑里的胶水 |
| **D. 一句话跨越** | 用一句完成时态的配音缝合，如"从水里上来之后的那几天，我们在镇上逛了很久" | 一句话同时交代时间跨度和地点变更，坦荡反而自然 |

## 第四步：事实错误自查

跨天素材最容易产生"事实错误台词"，发布前必须逐条自查：

| 危险词 | 问题 | 修正 |
| --- | --- | --- |
| "今天" | 素材跨天时是事实错误 | 改成"这次"/"这趟" |
| "第二天""第三天" | 暴露时间断层 | 删除，或用绳 2 的光线过渡替代 |
| "刚才" | 除非确为同一场景连续拍摄 | 改模糊表述 |
| 具体日期数字 | 除非刻意强调 | 通常删除 |

**全片不出现任何日期字卡**——这是刻意的，不是遗漏。

## 常见缺口与对策

| 缺口 | 对策 |
| --- | --- |
| 水下过程镜头缺失（设备受限） | 把"没法拍"做成信息差钩子；水下素材集中成快切段，密度即内容。——**但先确认是不是真的全程受限**（见第一步的误判提醒） |
| 出发前素材缺失，只有返航 | 返航段独立成戏——出发是期待，返航是消化，情绪落点更好 |
| 只有短素材（4–6 秒） | 用前后镜头包住，让它"出现—消失"，服务一句反转台词 |
| 静音段长镜头缺失 | 改用另一段静态素材（落日/空镜）承担静音功能 |
| 只有照片没有视频 | 用照片做字卡底图＋慢速推拉，或 0.5 秒闪帧埋钩子 |
| 素材组数少但每组长 | 集中成段落而非摊薄到全片 | 
| 素材类型杂（风景＋人物＋食物） | 用绳 1 的主题物件串起来，不要按类型分块 |
| **某段完全没有画面，但这段有信息要讲** | 不要用无关空镜糊弄。**先判断这段功能是"展示"还是"解释"**：是解释就交给字卡承载（详见 [title-card-spec.md](title-card-spec.md)）；是表现"缺失"就用空场具象化（黑场、空相册、空手腕） |
| **关键事件发生突然，没拍到过程** | 观众要的不是"过程"，是"结果和代价"。用字卡陈述结果＋给出教训；有凭证（收据、截图）优先用凭证 |
| **要对比两个方案但没拍到对比画面** | 做成对比表字卡，比找空镜高效得多；结论行延迟 0.5 秒出现做"揭晓"感 |

---

## 缺口的三种处理方式（按优先级）

1. **换钩子 / 换骨架**（缺口是承重墙时）——见第二步。
2. **字卡承载**（这段的功能是解释、陈述、对比）——见 [title-card-spec.md](title-card-spec.md)。
3. **空场具象化**（这段要表达"没有"）——黑场、空相册、空的手腕、"没有"用"空"表现。

**绝不用无关空镜填空**——这是最容易犯、也最伤片的错误。
