# 攻略片 / 干货片 / 避坑片手册

当片子定位从"旅行 vlog"或"情感故事"转为**经验型攻略片**时使用。这是本 skill 里最容易被做错的方向——做得像 vlog，主题就散了；做得像教程，又没流量。

## 定位判断

**攻略片的判定标准**：观众看完的动机是"我以后去做的时候用得上"（收藏），而不是"我看得很爽"（点赞）。

所以攻略片的核心指标是**收藏率**，不是完播率。所有设计围绕"这条信息值不值得存下来"。

**三个常见定位错误**：

| 错误 | 表现 | 后果 |
| --- | --- | --- |
| vlog 化 | 日常/逛街/风景段落抢走主线时长 | 主题散，观众不知道该看什么 |
| 教程化 | 全片讲原理，没有故事、没有失败、没有情绪 | 完播率低，没有传播 |
| 半吊子 | 又想讲故事又想讲干货，两边都不够 | 两头不讨好 |

**正确的比例**：潜水/技能/核心体验内容 **≥75%**，日常/周边 **≤25%** 且明确降级为呼吸口。

如果发现自己写的时候，日常段落（比如逛街）时长超过了核心段落，**就是 vlog 化了**，必须砍。

## 主题怎么定

**不要用"XX 怎么做""XX 需要准备什么"这类泛标题**——信息量低，没有钩子。

**好的攻略片主题一定含一个具体变量**：价格、门槛、时间、门槛破除、或一个意想不到的规则。

公式：

```
主题 =（一个具体数字或规则）+（一个反差或意外）
```

举例（从真实素材提出来的）：

- 「考 OW 潜水证，我花了 15000 泰铢，还赔了一千多」——数字＋意外损失
- 「考 OW：训练潜阶段你什么都拍不到」——一条别人不知道的规则
- 「XX 值不值：比另一家贵 2000」——决策型主题

（以上为示意表述，实际使用时替换为真实数字。）

**最强的攻略片主题形态是"预期管理"**：告诉观众"你以为的"和"实际的"差在哪。
例：「前 4 潜是训练潜，不允许拍摄；第 5、6 潜才是 fun dive」——这条信息的价值在于**观众下次自己会遇到，提前知道就不会失望**。这比"多少钱"更值钱。

## 结构模板

攻略片用**信息反转结构**，不用时间顺序。骨架：

```
0:00  钩子：数字前置 或 规则前置（"前四潜一张照片都没有"）
0:10  视觉最强段（把最好看的画面放开头，不用藏着）
0:40  反转：这么好的是"第 5 潜才有的" → 引出规则/干货
1:10  过程段：训练/准备都练什么（字卡密度最高）
2:00  段落钩子：一个稀缺的、不可复制的事件
3:00  真实失败段：代价、损失、教训
4:00  视觉第二高潮（静音段放这里）
4:30  干货段：费用明细 + 对比 + 选店逻辑 + 避坑清单（90–120 秒）
6:00  呼吸口：日常压缩 ≤20 秒
6:20  结算 + 金句收尾
```

**关键结构判断**：

1. **视觉最强的素材前置到开头**。这是攻略片与故事片最大的区别——故事片可以藏，攻略片必须前 40 秒就证明"这里有值得你存的东西"。
2. **反转点是全片分水岭**。用一句"但……"把观众的"想看"转成"想知道为什么"，干货段因此有了存在的理由，而不是硬插。
3. **干货段是承重墙，不是附录**。90–120 秒，位置在中后段（观众已经被故事说服、愿意接收信息时）。
4. **呼吸口必须短**。日常素材压缩到 15–20 秒，它的作用是让观众喘一口气，不是展示风景。

## 干货段怎么写

干货段里必须至少有这四类信息（缺哪类补哪类）：

| 类型 | 内容 | 为什么观众要 |
| --- | --- | --- |
| **费用明细** | 单价、总价、含什么、不含什么、另一家多少 | 决策依据，收藏理由 |
| **对比** | A 方案 vs B 方案，价差多少 | 帮观众省时间，最高价值 |
| **规则 / 门槛** | 什么能做、什么不能做、为什么 | 预期管理，避免踩坑 |
| **清单** | 3 条可执行的行动项 | 收藏点，"以后照着做" |

**写法纪律**：

- 每类信息用**字卡＋配音**双通道输出（见 title-card-spec.md）。
- 数字卡必须**停留足量**（4–5 秒），观众要抄。
- 清单卡用**逐条弹出**，每条 6 秒，让观众跟得上。
- **干货段不要加情绪音乐**，轻配乐垫底即可——这段的任务是让观众"看清楚"。

## 真实价格与数字的处理

**一个数字错了，整条片子的可信度就没了。**

纪律：

1. **全片数字唯一**。同一件事的所有表述（口播、字卡、标题、简介）必须完全一致。
2. **写进片子前，必须向本人复述确认**。本 skill 的真实教训：曾因未确认"这笔费用是单人价还是两人价"，导致整个干货段的结论方向错误（价差是"贵一点"还是"贵一倍"，是完全不同的两个故事）。
3. **区分"单人价"和"两人价"**——这是最容易搞错的一类。每次都要问："这个数字是一个人还是一共？"
4. **记错的数字要明确作废**，不要在有疑问的数字上继续推演。
5. **有价差才算好素材**。单纯报一个价格是流水账；有对比（A 多少钱、B 多少钱、差多少），才是决策信息。

**数字进片子的三种呈现**：
- 口播说一遍（听感）
- 字卡显示一遍（读感，可停留）
- 对比类数字做成表卡（结构感）

## 选店 / 选服务的写法与合规

好评实名是安全的，但有边界：

**可以说的（陈述事实）**：
- 这家店是谁开的（"澳洲人开的"）
- 服务内容（"中文潜导带我们写日志、讲鱼种"）
- 价格与包含项
- 具体的行为描述（"每一潜都带我们回顾问题"）

**不能说的（绝对化表述）**：
- "最靠谱""全岛最好""强烈推荐"
- 没有依据的定性（"这家店比别家专业"）

**合规三条**：
1. **只陈述有证据的事实**，不做定性评价。
2. **引用他人原话必须注明是引用**（"潜导说：……"），不能变成自己的判断。
3. **涉及第三方机构**（旅行社、潜店、平台）时，只讲自己的经历，不替对方做承诺。

**加分做法**：把"为什么选它"写成**决策依据**，而不是"推荐"。观众要的是"我怎么选"，不是"你推荐哪个"。决策依据可复制，推荐不可复制。

## 真实失败是最好的干货

攻略片最缺、也最值钱的内容是**真实的代价**。

所有人都在讲"要准备什么"，很少有人讲"**没准备好会花多少钱**"。

**处理原则**：
- 失败段不要煽情、不要自嘲过度，**平静陈述 ＋ 给出教训**即可。
- 失败的画面通常拍不到（事发突然），所以**必须用字卡承载**（见 title-card-spec.md 范例一）。
- **有凭证就用凭证**：赔偿收据、转账记录、罚单、维修单——真实凭证比任何镜头都强，打码也能用。
- 失败段后面必须紧跟**一条可执行的教训**（"每次下水前检查装备"），否则观众只看到倒霉，学不到东西。

**真实失败的三种形态**（按价值排序）：
1. **花了钱**（赔偿、罚款、重复购买）——最有说服力
2. **白费了时间**（错过了、走错了、排错了队）
3. **尴尬**（操作失误、被纠正）——价值最低，但最易得

## 金句的两次出现法

一句好的引用（教练的话、当地人的话、同伴的话）可以用两次，形成回环：

| 位置 | 出现方式 | 作用 |
| --- | --- | --- |
| 中段（约 60% 处） | 作为**他人的话**出现，注明是谁说的 | 交代人物、风格、态度 |
| 收尾 | 变成**"我记住了"** | 完成从他人话语到自己体悟的转化 |

两次之间间隔 2–3 分钟，回环成立。

**这比只用一次强得多**——它把一句引用变成了一个主题。收尾不能再放新信息，只能放已经出现过的东西的"回响"。

## 定位自查

写完分镜后，用这几条自查：

- [ ] 核心内容（潜水/技能）占比是否 ≥75%？日常是否 ≤25%？
- [ ] 主题是否含一个**具体变量**（数字/规则/反差），而不是"XX怎么做"？
- [ ] 视觉最强的素材是否在前 40 秒出现？
- [ ] 是否有**反转点**（"但……"）把观众从"看"转到"想知道"？
- [ ] 干货段是否 ≥90 秒，且含费用＋对比＋规则＋清单四类信息？
- [ ] 全片数字是否唯一且已向本人确认？
- [ ] 失败段是否有代价，后面是否跟了可执行教训？
- [ ] 日常呼吸口是否 ≤20 秒？
- [ ] 收尾是否只放"回响"，不放新信息？
