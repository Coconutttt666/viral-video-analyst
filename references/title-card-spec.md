# 字卡规格（样式、动效、验收）

字卡＝画面上叠加的文字卡片（不是字幕，字幕是配音的逐字稿）。
**核心认知：字卡在一些片种里不是辅助，而是与实拍画面并列的第二条视觉主线。**

判断是否该把字卡升格为主线：数一数片中有几个镜头没有可用画面。≥3 个，字卡就应按主线的标准设计，而不是当补丁用。

## 什么时候字卡必须当主线

三种情况，字卡承担不同职责：

| 情况 | 字卡职责 | 手法 |
| --- | --- | --- |
| 这一段的功能是**解释**（讲原理、讲费用、讲规则） | 字卡即画面，信息量就是视觉 | 纯色底＋逐条弹出 |
| 这一段要表现**缺失**（"我一张照片都没有"） | 用"空"来表现"没有" | 黑场、空相册、空手腕等具象化的空场 |
| 这一段要**对比**（A 方案 vs B 方案） | 字卡比画面更高效 | 对比表卡，带"揭晓"式延迟出现 |

**不要把"没画面上字卡"当权宜之计。** 攻略片、知识片的信息（价格、对比、清单、教训）本来就适合字卡承载，用画面反而讲不清。坦荡地用字卡，比硬凑空镜专业得多。

## 基础样式规格

**全片只用一套，不允许一张一个样。**

| 项 | 规格 |
| --- | --- |
| 字体 | 思源黑体（免费商用）或苹方 |
| 字重 | Medium。**不加粗、不加描边、不加发光** |
| 字色 | 白 `#FFFFFF` |
| 底框（压在实拍画面上时） | 40% 黑底 `rgba(0,0,0,0.4)`，圆角矩形，内边距约为字号的一半 |
| 底图（无实拍素材时） | 深海蓝纯色 `#0A2A43`，白字。**全片此类字卡必须统一** |
| 强调色 | 选一个高饱和暖色（如 `#E86B5A`），**全片只用于"负面数字"**（赔偿、多花、损失），其他数字一律白色 |
| 分辨率基准 | 1920×1080 |

**强调色的用法**：给负面数字标记颜色，会让观众对"哪里让我花了冤枉钱"产生颜色记忆。这是避坑类内容里有效但少见的处理，一部片子只绑 2–3 个数字，不要滥用。

## 字号与位置

（以 1080P 为基准；成片后按手机屏复核，见"验收标准"）

| 类型 | 字号 | 位置 | 用于 |
| --- | --- | --- | --- |
| 数字 / 价格卡 | 72–90px | 屏幕正中偏下 | 价格、赔偿、对比数字 |
| 说明文字 | 36–44px | 紧贴数字下方或卡内 | 数字卡的补充说明 |
| 清单卡 | 48–56px | 屏幕中央，每条一行 | 技能清单、避坑三条 |
| 金句卡 | 64–80px | 屏幕正中 | 引用、收尾金句 |
| 常驻标题（可选） | 32–36px | 屏幕顶部安全区内 | 全片常挂，如「XX 考证 ｜ 花了多少钱」 |

**停留时长 = 字数 ÷ 4 秒**。一张卡最多两行、每行不超过 12 字，超过则拆成两张。**低于 3 秒的字卡观众读不完。**

## 动效（只用两种）

1. **淡入淡出**——占全片约 90%。0.3 秒淡入 → 停留足量 → 0.3 秒淡出。
2. **逐条弹出**——只用于清单卡。首条淡入后停 0.5 秒，次条再淡入，依次出现；退场时整组一起淡出。

**揭晓式延迟**：对比类字卡可以让结论行（如"多花 1900/人"）**比数据行晚 0.5 秒出现**，制造"揭晓"感。

**禁止使用**：打字机效果、飞入飞出、旋转、缩放弹跳、任何带音效的字卡转场。
这些会把片子从"攻略片"降级成"营销号"，是风格红线。

## 两个常用范例

**范例一：三段式叙事卡**（用于讲一个有代价的事件）

```
[深海蓝底]
   第五潜                    0.3s 淡入 → 停 4s → 0.3s 淡出

[深海蓝底]
   潜水电脑表
      掉了                   停 4s → 淡出

[深海蓝底]
   赔偿 1000+ 元             "1000+"用强调色，停 4s → 淡出
```

**范例二：对比表卡**（全片最重要的一张，用于讲选型决策）

```
┌───────────┬───────────┐
│  A 方案   │  B 方案   │
│  13000/人 │  15000/人 │
└───────────┴───────────┘
      多花 2000/人            ← 这一行最后 0.5s 才淡入，做"揭晓"感
```

（上表数字为示意值，实际使用时替换为真实价格。）

## 验收标准

字卡做完，**必须用手机看一遍**。判定只有一条：

> **在手机屏幕上一眼读得清，并且能在它消失前读完。**

电脑上看着合适的字号，手机上手机会偏小——**按手机标准调，不要按电脑调**。
读不完就**拆成两张**，不要延长停留时间（延长会让节奏拖沓）。

## 找参考的方法

不给具体视频链接（链接会失效、内容可能与描述不符，比不给更糟）。给可执行的动作：

1. **在用户自己的 App 里搜**（小红书/抖音/B站），搜目标题材的攻略关键词，按"最热"排序。
2. **看字卡，不看内容**。记录：字卡在第几秒出现、停留多久、什么字体、有没有底框。
3. **用收藏量筛**。收藏量高的攻略视频，字卡一定清楚——观众收藏就是为了"以后照着做"。**收藏量是字卡质量的直接指标。**
4. **截图建参考库**。攒 20 张，就有了自己的模板库，比看任何教程有效。

**建议模仿的组合**：攻略片的写法（常驻标题＋弹卡）＋知识区的克制（弹卡不花哨）。
