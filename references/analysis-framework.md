## 第一步：深度拆解与数据标注

### 1.1 结构与节奏分析

**Pacing（节奏）**
- 标出脚本在哪里**放慢**（建立情感、制造停顿），在哪里**加速**（创造冲击、删除冗余）。
- 慢下来的地方通常是：狼狈/失败的过程、危机时刻、无台词的情绪段。
- 快起来的地方通常是：高潮混剪、信息密集的干货段。
- 用【快】【慢】【中】【变速】在时间轴上逐段标注。

**Hook Points（钩子点）**
- **主钩子**：前 3 秒（前 30 秒内必须完成价值承诺）。标记其类型和字卡/台词原文。
- **段落钩子**：每 30 秒一个，用于维持留存。标出具体转折点和触发它的那句话。

**Payoffs（回报点）**
- 所有"价值交付"时刻：揭晓秘密、给解决方案、情感高潮、身份达成。
- 每条钩子都必须有对应的回报，否则是"空钩"——观众会感到被骗。

### 1.2 观众心理分析

**核心情感曲线**：用箭头链画出观众从开头到结尾的情绪旅程，例如：
`好奇 → 怀疑 → 震惊 → 共鸣 → 行动`

**Targeting（痛点 / 爽点）**：明确指出脚本打击了观众的哪个核心痛点、恐惧、渴望或爽点。不要写"引起共鸣"这类空话，要写具体是"怕水的人的窒息恐惧"或"考证失败者的自我怀疑"。

**修辞与框架**：识别使用了哪些说服技巧，常见的有：
- 建立共同敌人（"那些骗人的低价团"）
- "我们"式对话感（拉近距离）
- P.A.S. 框架（Problem → Agitation → Solution）
- 反常识框架（先说一个大众误解，再打脸）
- 自我否定式开场（"我花了很久才承认……"）

### 1.3 算法亲和度分析

**关键词植入**：核心关键词如何自然分布在标题、开头和内容中。判断标准：每个词是否出现在它对应的真实场景里（做耳压时讲耳压，跑船时讲晕船），而不是堆砌。

**互动触发器**：促使点赞、留言、分享的具体设计——争议性观点、开放性问题、要求站队、纠错诱饵（故意说错引圈内人纠正，高风险高收益）。

**会话时长设计**：结尾如何引导观看下一个视频或播放列表；是否有系列化钩子。

## 第二步：提取爆款 DNA

**总结核心公式**：用一行公式概括，形如：

```
公式 =（钩子类型）+（结构装置）+（回报设计）+（收尾）
```

**识别关键模式**：归纳可复用的叙事模式、钩子类型或情感操纵技巧。每个模式给一句"为什么有效"。

**在这一步停下，等用户确认后再进入第三步。**

---

## 第三步：策略蓝图与优化建议

### 3.1 可复制的策略（Replication Strategy）

- **保留什么**：哪些元素是成功关键，未来必须保留。建议列成"必保项"清单，并标注"动了就废"的核心项。
- **优化什么**：哪些可以做更好（钩子更短、CTA 更强、情感铺垫更足）。

### 3.2 风险与规避（Risk Assessment）

识别潜在风险并给方案：
- 过度依赖热点（热点过气即失效）
- 触及社区规范边缘（各平台红线不同）
- 观众疲劳（同一模式重复使用）
- 事实错误（会被评论区抓住）
- 合规问题（商业关系未披露、绝对化表述、肖像权、平台限流内容）

### 3.3 写作 SOP

3–5 条可操作的脚本写作准则，供脚本专家或 AI 在下一步创作时遵循。每条要足够具体到可以直接执行。

## 第四步：5 个可扩展新选题

基于第二步的 DNA 生成 5 个全新高潜力选题。每个必须含：

| 字段 | 要求 |
| --- | --- |
| 选题标题（Tentative Title） | 前 12 字须含地域＋行为（若适用） |
| 核心钩子（Core Hook） | 计划如何抓住观众，写具体台词或画面 |
| 成功率预判（Rationale） | 为什么它会成功——即它如何应用了第二步的公式 |

**在这一步前必须已获得用户对第三步的确认。**

## 通用钩子与模式库

### 钩子强度排行（从强到弱）

| 类型 | 示例 | 为什么有效 |
| --- | --- | --- |
| 恐惧前置 | "下水前，教练让我把面镜摘掉。" | 生理级恐惧，观众本能代入 |
| 反常识 | "不会游泳也能潜水。" | 认知冲突，必须看下去验证 |
| 结果前置 | 直接给高潮画面，0 台词 | 画面本身就是钩子 |
| 信息差 | "教练不让我们带相机下水。" | 观众想知道"为什么" |
| 悬念断裂 | "这是我最后一潜，但我不知道。" | 信息不对称制造紧张 |

### 可复用叙事模式

1. **三障碍法则**：小障碍 → 大障碍 → 危机转折点。每个障碍对应观众的一个自我怀疑。
2. **压缩转变弧**：惊人结果 → 谦卑起源 → 量化转变 → 励志收尾。
3. **三幕短结构**（45 秒）：hook（0–10s）→ 挣扎（11–35s）→ 回报（36–45s）。
4. **Teaser 反时间线**：先给戏剧性瞬间 → "12 小时前……"。
5. **静音对比**：全片有配乐，唯高潮段撤掉全部音乐，只留环境声。稀缺性＝记忆点。
6. **身份跃迁**：Before（游客/外行）→ After（持证者/内行），片尾必须出现可视化凭证。
7. **对照组结构**：同一技能，两种结果（适合双人/多人题材）。
8. **金句收尾**：一句情绪价值短句概括全片。

### 每 30 秒规则

全片每隔 30 秒必须有一个信息点或情绪转折。没有口播填充时，信息密度必须靠剪辑和字卡撑起来。
