## 案例一：海岛潜水考证视频（旅行＋技能习得类）

**题材**：两个人去东南亚某海岛学 OW 潜水考证，做成 6 分钟主片。
**约束**：不露脸口播，纯配音；分镜可露脸；双人同行。

### 核心公式

```
公式 =（一个生理级的具体恐惧，越具体越好）
     ＋（一个反常识的门槛破除）
     ＋（三障碍递进：装备的狼狈 → 身体的对抗 → 心理的自我怀疑）
     ＋（水下唯一静音段作为情感高潮）
     ＋（一个"没人告诉你"的信息差）
     ＋（身份跃迁收尾：从游客到持证潜水员）
```

### 关键模式

| # | 模式 | 说明 |
| --- | --- | --- |
| 1 | 恐惧前置钩子 | "教练摘掉了我的面镜"——生理级恐惧，观众本能代入窒息感 |
| 2 | 三障碍法则 | 每个障碍对应观众的一个自我怀疑 |
| 3 | 静音对比 | 全片有配乐，唯水下高潮段撤掉全部音乐，只留呼吸声 |
| 4 | 身份跃迁 | Before（旱鸭子）→ After（持证潜水员），片尾出现证书 |
| 5 | 双人对照组 | 同一技能两种结果（她一次做成 / 我做了三次） |
| 6 | 手部替身 | 纯配音模式下，手是脸的替身；呼吸是语气的替身 |

### 实拍后的重大修订（重要教训）

**实际素材与原方案严重不符**：教练严格，训练潜全程不许学员带机下水，实际只拍到跳水、两人水中打招呼（5–8 秒）、鱼群。原方案的承重镜头（面镜 POV、泳池、潜伴 OK 手势、危机段）**部分缺失**。

**处理方式**：
1. **换钩子**：恐惧前置 → 信息差前置（"教练不让我们带相机下水，水下的每一秒都是借来的"）。把缺口转成主题。
2. **水下素材集中快切**：不摊薄到全片，前 40 秒一段快切交付完，密度即内容。
3. **新增承重墙**：原方案未预料的陆地素材（街区十几条、一项水上活动 5–6 秒、海边落日）升格为主力。
4. **静音段换形式**：水下双人呼吸 → 返航环境声（引擎/浪/风）。
5. **收尾升级**：落日＋证书双结算（光的结束和身份的达成放在一起）。

**跨天串联**：潜水/街区/海边不在同一天。处理方式见 [footage-adaptation.md](footage-adaptation.md)——按"水的递减"动线重排（水下 → 水上 → 看着水），加证书钩子绳（开头闪帧预告）。

**事实错误修正**：原稿"这是我今天第二次下水"→ 改为"这是我这次第二次下水"（跨天，说"今天"是事实错误）。

### 第二轮回溯：前提问错，三个版本全部作废（最重要的教训）

**发生了什么**：第一轮"缺少水下素材"的结论，基于用户**未说明**的素材情况直接推演，连写了三个版本（v1 攻略＋情感、v2 跨天串联、v3 旅行 vlog），还额外做了一整套"AI 生成素材替代方案"（含文生视频提示词、AI 占比测算、合规模拟标注）。

**真相**：后段 fun dive 阶段，**教练帮拍了 3 分钟以上水下素材，且拍到两人正脸**。前段训练潜才不允许拍摄。
"没素材"从根上就是错的 → 三个版本全部建立在错误前提上 → AI 方案在素材充足时完全没有存在必要。

**错在哪**：把用户一句"教练比较严格"当成了"全程不能拍"，**没有追问素材的实际条数、时长、是否有人脸**。

**修正后的做法**：
1. **核对素材必须问三件事**：每组的**条数**、**总时长**、**是否拍到人脸**。（这条已写进 footage-adaptation.md）
2. **决定结构的数字必须复述确认**：价格（单人还是两人）、人数、天数、素材量，一次问清。
3. **主题跟着素材事实走**：素材从"几乎没有"变成"有 3 分钟"，主题就必须从"信息差"（水下的每一秒都是借来的）改成"预期管理"（训练潜阶段什么都拍不到）——**旧主题在新事实下会显得矫情**。
4. **视觉高潮的位置跟着素材走**：素材充足时，最好的画面**前置到开头**（0:10–0:40），不要藏在中后段。

**最终定稿结构**（攻略版）：钩子（费用数字 / 训练潜没照片）→ 视觉高潮前置 → 反转（"这是后段 fun dive 才有的"）→ 训练段（字卡承重）→ 稀缺事件钩子 → 真实失败（装备损失）→ 幸运段静音段 → 干货段 90 秒 → 呼吸口 20 秒 → 证书结算＋金句收尾。

### 定稿过程中的其他可迁移结论

| 结论 | 说明 |
| --- | --- |
| **没画面上字卡，不是权宜之计** | 五个"没有画面"的镜头里四个最终由字卡承担。攻略片的信息（价格/对比/教训）本来就适合字卡，用画面反而讲不清 |
| **"缺失"要用"空"来表现** | "前几潜我一张照片都没有"配海面空镜无效；改用手机相册划过一排无水下照，落差直接砸在眼睛上 |
| **价格有对比才是好素材** | 单一报价是流水账；A 多少钱、B 多少钱、差多少，才是决策信息（本例：一家比另一家每人贵几百元） |
| **他人原话要出现两次** | 教练金句（如"要照片还是要命"）：中段作为他人的话出现，收尾变成"我记住了"，把引用变成一个主题 |
| **有凭证就用凭证** | 赔偿收据/转账截图比任何镜头都强，打码也能用 |
| **稀缺事件是天然段落钩子** | 拍摄当天恰有特殊事件导致码头封锁、所有船只在海上排队——真实、不可复制、无法拍摄 |
| **"幸运"需要实证** | "潜导几个月没去过某潜点，我们去了水况还不错"——让"幸运"这个抽象情绪有了具体事实支撑 |

## 案例二：跟团游旅行视频（多人团体类）

**题材**：4 人（用户＋3 个朋友）报某旅游平台的跟团游，做旅行视频。
**注意**：案例一的 DNA 不能直接搬——跟团游没有水下、呼吸、潜伴元素。

### 核心公式

```
公式 =（出发前的怀疑钩子：会不会是购物团）
     ＋（高原反应低谷）
     ＋（奇观递进）
     ＋（多人团体的情感高点）
     ＋（诚实报告：人均花费＋团怎么样）
     ＋（关系跃迁：从朋友到"一起走过长线行程的搭子"）
```

### 关键模式

| # | 模式 | 说明 |
| --- | --- | --- |
| 1 | 怀疑钩子 | "我妈第一句话：会不会是购物团"——贴近目标观众的真实顾虑 |
| 2 | 诚实报告收口 | 人均花费总账＋团值不值，形成钩子—回报闭环 |
| 3 | 多人主角轮值 | 每天一个主角（管钱的、易高反的、体力好的、爱美的），解决多人出镜对等 |
| 4 | 生理低谷 | 高反是唯一可迁移的生理钩子（对应案例一的恐水） |
| 5 | 环境声主角 | 呼吸声 → 环境声（金沙江咆哮、篝火歌声、猪槽船水声） |
| 6 | 两个"错过就没有"的镜头 | 第一眼奇观（谁先跑上去谁回头拍其他三张脸）、30 秒不说话的固定镜头 |

### 合规重点

- 评价旅行社的**法律边界**：只陈述有证据的事实（合同、票据、停留时间），不做"骗子""黑店"式定性；先留证据再决定发不发。
- 购物店入镜、团友肖像权、高反安全不可娱乐化、少数民族文化不用流传误解表述（如"随便走婚"）。

## 可迁移的通用结论

1. **生理钩子最强**：恐水、高反、恐高——凡是身体本能反应的，代入感最强。旅行/技能类题材优先找这个。
2. **缺口即主题**：拍不到的东西往往是最好的钩子素材。——但前提是**先确认真实素材情况**（见案例一的教训：误判"缺素材"导致三版作废）。
3. **诚实报告 = 高流量池**：消费类内容（跟团游、低价团、人均花费）自带"避坑"需求，但合规风险也最高。
4. **静音段是纯配音模式的独占优势**：口播者在静态/水下场景没法说话，配音者可以主动选择沉默。
5. **素材决定结构**：永远先核对素材，再定结构。
6. **关键数字必须复述确认**：价格是单人还是两人、素材是 5 秒还是 3 分钟——**一个没问清的数字可以让整个结构作废**。
7. **主题会随素材事实改变**：素材从"几乎没有"变成"很充足"时，主题必须跟着换（信息差 → 预期管理），否则旧主题会显得矫情。
8. **字卡可以是第二条视觉主线**：无画面镜头 ≥3 个时，字卡应按主线标准设计，而不是当补丁。
9. **攻略片要 75% 核心内容**：日常段落一旦超过核心段落时长，就是 vlog 化，必须砍。
10. **真实失败是最贵的干货**：所有人讲"要准备什么"，很少有人讲"没准备好会花多少钱"。有凭证就用凭证。
